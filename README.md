# MasterBook

Кроссплатформенное мобильное приложение
для онлайн-записи клиентов к мастерам услуг.

## Technologies

- Flutter
- Dart
- Go
- PostgreSQL
- REST API
- Docker

## Project structure

- backend — Go API
- mobile — Flutter application
- deploy — deployment configuration
- docs — project documentation

## Демонстрация дипломного проекта

Для защиты удобно демонстрировать веб-версию: `http://103.118.208.191:8080`.

Полный сценарий: клиент регистрируется/входит → выбирает мастера и услугу → выбирает свободное время → создает запись → мастер входит в кабинет → подтверждает запись → клиент видит уведомление.

Подробный сценарий и пункты для объяснения находятся в [docs/demo.md](docs/demo.md).
