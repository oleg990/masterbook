# Демонстрация MasterBook на защите

Для защиты дипломного проекта можно демонстрировать только веб-версию MasterBook. Мобильное Flutter-приложение остается в репозитории как дополнительная часть проекта, но для основной демонстрации не требуется.

## Что показывать

1. Открыть:
   `http://103.118.208.191:8080`

2. Показать главную страницу:
   - каталог мастеров;
   - услуги;
   - адаптивность страницы.

3. Войти под учетной записью клиента.

4. Выбрать мастера и услугу.

5. Выбрать свободную дату и время.

6. Создать запись.

7. Открыть «Мои записи» и показать статус `Ожидает подтверждения`.

8. Выйти и войти под учетной записью мастера.

9. В кабинете мастера открыть «Записи клиентов».

10. Подтвердить запись.

11. Вернуться к клиенту и показать уведомление «Запись подтверждена».

12. При необходимости показать отмену или завершение записи.

## Что объяснять

### Архитектура

Система состоит из трех основных частей:

- веб-интерфейс на HTML, CSS и JavaScript;
- REST API на Go;
- PostgreSQL для хранения пользователей, мастеров, услуг, расписания, записей и уведомлений.

Веб-интерфейс и мобильное Flutter-приложение используют один и тот же REST API.

### Почему веб-версия подходит для демонстрации

Для защиты достаточно показать браузерный интерфейс. Он позволяет продемонстрировать полный пользовательский сценарий:

клиент → выбор мастера → выбор услуги → свободное время → запись → подтверждение мастером → уведомление клиента.

### Что показать в коде

Достаточно открыть:

- `backend/cmd/server/main.go` — маршруты REST API;
- `backend/internal/appointments/handler.go` — создание записи и проверку пересечений;
- `backend/internal/appointments/availability.go` — формирование свободных слотов;
- `backend/internal/appointments/master.go` — подтверждение, завершение и отмену записи;
- миграции PostgreSQL — структуру базы данных;
- `backend/web/index.html` — клиентский веб-интерфейс.

Не нужно подробно разбирать каждую строку. Важно объяснить назначение каждого слоя и показать один сквозной сценарий.

## Короткий текст для выступления

«Я разработал информационную систему MasterBook для онлайн-записи клиентов к мастерам. Пользователь может зарегистрироваться, выбрать мастера, услугу и свободное время, после чего создать запись. Мастер видит входящие записи и может подтвердить, завершить или отменить их. После изменения статуса клиент получает уведомление. Серверная часть реализована на Go, данные хранятся в PostgreSQL, а взаимодействие клиента и сервера выполняется через REST API. Для демонстрации проекта я использую веб-версию системы, работающую на сервере.»

## Что не нужно показывать

Не требуется запускать Docker-команды, настраивать VPS или демонстрировать сборку APK во время защиты. Это лучше оставить как сведения о развертывании проекта в пояснительной записке.
